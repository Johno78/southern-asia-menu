# Takeaways

Isle of Man takeaway menus as one installable web app.

- `index.html` is the home screen listing each takeaway
- `southern-asia.html` Southern Asia, Port Erin
- `yummy-house.html` Yummy House, Anagh Coar
- `rush-inn.html` Rush Inn, Castletown
- `mandarin.html` Mandarin Takeaway, Port Erin
- `simple.html` Simple (pizza and kebabs), Port Erin
- `la-gusto.html` La Gusto Pizza, Port Erin

To add a takeaway, copy one of the menu pages, replace its menu data, and add an entry to `PLACES` in `index.html` and the page to `CORE` in `sw.js`.
